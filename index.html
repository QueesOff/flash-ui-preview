3 · Что уходит на сервер
Событие

Пуш 5000 BOB от боливийского банка

{ "device_uuid": "7f3a9c2e-…", "binding_uuid": "uuid-bolivian…", "source": { "type": "push", "package": "example.bank.bolivia" }, "content": { "text": "Вы получили перевод 5000 BOB" }, "received_at": "2026-11-04T…" }
Привязка по пушу: package → реквизит.
Связка: прога + app name + рек + сумма.
Тип пуша (начисление/списание) разбирает сервер.
Правила
1 банк = 1 реквизит на одном девайсе
На 1 проге может быть до 10 банков
Дубль банка → вторая прога / девайс
